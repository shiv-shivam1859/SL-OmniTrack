1.What is this Project?

 Name - SL-OmniTrack
 - "SL" stands for my future startup called "Silicon Labs" and "OmniTrack" is the kit name. This is a kit which includes 2 main things -

 - The ground Station - It comes in a 3d printed enclosure which has a microcontroller , LoRa transceiver , power package and a usb cable going from microcontroller to outside of enclosure for user to connect it to the system.

 - Main Avoinics bay - It comes in cylindecal shape outline enclosure with diff. diameter option. It has microcontroller , IMU , Barometric sensor , Camera , Micro SD module (To save flight data) , Power package. (Some changes in component will be updated in BOM so for final list check BOM instead of README.md)

 - Both enclosure has switch to power the system , both microcontroller's code make sure's that as soon as microcontroller receive power from battery both of them connects to each other wirelessly. 
 - Enclosure also give freedom to flash your own code.
